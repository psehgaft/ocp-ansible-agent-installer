= Module 2 Lab 1: Discover iLO and iDRAC

*Lab Type:* Read-only discovery.

*Estimated Time:* 20–30 minutes.

== Learning Objectives

* Discover Redfish resource IDs.
* Collect hardware and firmware evidence.
* Validate provisioning MAC selection.

== 1. Run discovery

[source,bash]
----
ansible-playbook -i inventories/lab/hosts.yml --ask-vault-pass playbooks/01-discover-bmc.yml
----

== 2. Review evidence

[source,bash]
----
cat artifacts/ocp418-lab/reports/bmc-inventory.md
jq '.normalized_nics, .provisioning_mac' artifacts/ocp418-lab/raw/bmc-master-0.json
----
