= Module 6: Deploy a Cluster from ACM

This module converts the validated framework inputs into an ACM-managed cluster deployment.

== Required variables

[source,yaml]
----
acm_cluster_name: spoke01
acm_base_domain: example.com
acm_openshift_version: "4.18"
acm_pull_secret_file: secrets/pull-secret.json
acm_ssh_public_key_file: secrets/id_rsa.pub
acm_control_plane_replicas: 3
acm_worker_replicas: 3
acm_api_vip: 192.168.50.10
acm_ingress_vip: 192.168.50.11
acm_machine_network_cidr: 192.168.50.0/24
acm_cluster_network_cidr: 10.128.0.0/14
acm_service_network_cidr: 172.30.0.0/16
----

== 6.1 Generate cluster template

Render the cluster definition before committing or applying it:

[source,bash]
----
ansible-playbook playbooks/acm/generate-cluster-template.yml \
  -e @inventories/lab/group_vars/acm-cluster.yml \
  -e day2_deployment_mode=render
----

Verify the generated cluster name, OpenShift release image, replicas, pull-secret reference, and SSH key reference.

== 6.2 Generate cluster network definition

[source,bash]
----
ansible-playbook playbooks/acm/generate-network-definition.yml \
  -e @inventories/lab/group_vars/acm-cluster.yml \
  -e day2_deployment_mode=render
----

Confirm that API, ingress, machine, cluster, and service networks do not overlap and match the physical network design.

== 6.3 Validate cluster template

[source,bash]
----
python scripts/validate_yaml.py
python scripts/validate_kubernetes_manifests.py
oc apply --dry-run=server -f rendered/acm/spoke01/
----

Do not continue while placeholders, invalid references, duplicate IP addresses, or schema errors remain.

== 6.4 Deploy cluster

Direct mode:

[source,bash]
----
ansible-playbook playbooks/acm/deploy-cluster.yml \
  -e @inventories/lab/group_vars/acm-cluster.yml \
  -e day2_deployment_mode=direct
----

GitOps mode:

[source,bash]
----
ansible-playbook playbooks/acm/deploy-cluster.yml \
  -e @inventories/lab/group_vars/acm-cluster.yml \
  -e day2_deployment_mode=gitops

git add rendered/acm/spoke01
git commit -m "Add ACM managed cluster spoke01"
git push
----

== Verification

[source,bash]
----
oc get managedcluster spoke01
oc get clusterdeployment -A
oc get agentclusterinstall -A
oc get agents -A
----

The managed cluster must become available, accepted, and joined to the hub before Day-2 policies are applied.
