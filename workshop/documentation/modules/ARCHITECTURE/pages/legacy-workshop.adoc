= Workshop Source Map

This page maps the complete workshop into one sequential learning path. The original Day-0 procedures remain under `workshop/documentation/modules/ROOT/`, while architecture, platform-operator, GitOps, health-check, and extensibility content remains under `workshop/documentation/modules/ARCHITECTURE/`.

The sequence is intentional:

. Prepare the workstation, inventory, dependencies, and credentials.
. Validate Redfish discovery and virtual media.
. Install and verify OpenShift.
. Apply ordered Day-2 foundations: NTP, node labels, identity, operators, storage, networking, observability, and backup.
. Run health checks and learn how to add components and templates.
. Generate, validate, and deploy a managed cluster from ACM.
. Complete the integrated final challenge.

Use the `ROOT` pages for executable bare-metal procedures and the `ARCHITECTURE` pages for framework design, deployment modes, component catalogs, policies, and extension guidance.

All numbered pages are exposed through the workshop navigation. Each lab ends with a link to the next sequential module so participants can follow the complete path without returning to the navigation menu.
